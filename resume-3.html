Featured Project

Kuttl: AI-Powered UI Customization Layer | Founder & Engineer
2026 - Present
One script tag gives any web app a prompt box. Users type things like "show this as a table instead of cards" and the interface changes instantly, with no page refresh, and it stays that way. Live demo: open kuttl.xyz and use the ✦ panel to change the site itself.
  • Designed and built the whole product solo: the client SDK, the AI planning pipeline, the hosted backend, the docs site and the landing page.
  • Built a vanilla JS interception layer that applies user changes to the DOM before paint, so there's no flicker. Changes survive reloads and browser restarts.
  • Built a React runtime integration that hooks into React's fiber reconciler, so changes to component props and structure happen above the DOM and don't fight React's re-renders.
  • Built the LLM pipeline that turns a prompt plus the page structure into structured, validated patches. Changes are reversible, and it degrades gracefully when the model makes a mistake.
  • Built a Go proxy that holds the LLM credentials so no API keys reach the browser, plus locked regions so teams can protect pricing tables, legal text and other critical UI from edits.
  • Shipped as both a CDN script tag and an npm package (Vite, webpack), with a quick-start guide that takes under 5 minutes. Now onboarding early-access teams.
Stack: TypeScript, React (fiber internals), Go, LLM APIs, structured output, npm / CDN distribution
